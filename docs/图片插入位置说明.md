## 操作步骤

### 第一步：生成技术架构图（图1-8）

1. 打开AI图像生成工具（推荐ChatGPT或Midjourney）
2. 复制`图片生成提示词.md`中对应图的English Prompt
3. 粘贴到AI工具并生成
4. 检查生成质量：
   - ✅ 文字清晰可读
   - ✅ 逻辑关系正确
   - ✅ 配色专业（蓝灰色系）
   - ✅ 分辨率足够（至少1920px宽）
5. 保存为PNG格式，命名为`图1_防抖锁工作原理.png`等
6. 如果AI生成效果不理想，可使用备选方案：
   - **Draw.io**：打开 https://app.diagrams.net/ 手绘
   - **已有Mermaid代码的图7**：使用 https://mermaid.live 渲染并导出

### 第二步：截取界面图片（图9-19）

1. 启动完整系统：
   ```powershell
   # 启动后端
   python app.py
   
   # 启动前端（另一个终端）
   cd frontend
   npm run dev
   
   # 启动虚拟机上的探针
   python scripts/monitor_client.py
   ```

2. 访问 http://localhost:3000 进行截图

3. 截图建议：
   - 使用Windows截图工具（Win + Shift + S）
   - 确保界面数据真实（有真实监控数据、日志、告警记录）
   - 隐藏敏感信息（如真实邮箱地址可打码）
   - 保持界面整洁（关闭浏览器开发者工具）
   - 统一分辨率和比例

4. 保存为PNG格式，命名规范：`图9_登录界面.png`

### 第三步：插入论文

在Word版论文中对应位置插入图片：

1. 打开最新的Word论文文档
2. 定位到对应的"如图X所示"位置
3. 在该句话后面（新的一行）插入图片
4. 调整图片大小（建议宽度14-16cm，适应A4纸张）
5. 设置图片居中对齐
6. 在图片下方添加图注：
   ```
   图1 防抖锁工作原理
   ```
7. 检查图注编号与正文引用是否一致

### Word插入图片快捷操作

1. 选中"如图1所示。"后的空行
2. 插入 → 图片 → 来自文件
3. 右键图片 → 大小和位置 → 宽度设为14cm，保持纵横比
4. 右键图片 → 环绕文字 → 嵌入型（学术论文推荐）
5. 图片下方新起一行，输入图注（居中对齐，小五号字体）

## 常见问题

**Q: AI生成的图文字模糊怎么办？**
A: 重新生成时在提示词中强调"sharp text, high resolution, vector graphics"，或使用Draw.io等专业工具手绘。

**Q: 论文中图片太大占用页面怎么办？**
A: 调整图片宽度为12-14cm，复杂的架构图可以横向排版，宽度16cm。

**Q: 图片在Word中模糊？**
A: 确保插入时选择"原始大小"，不要过度缩放。如果还模糊，检查原图分辨率是否足够。

**Q: 没有Midjourney账号怎么办？**
A: 可以使用免费的ChatGPT（GPT-4o带DALL-E 3），或者使用Draw.io手绘所有图表。

**Q: 系统界面还没开发完怎么办？**
A: 图9-19可以先用同类系统的参考图或者设计稿占位，后期替换真实截图。
