## 图1：防抖锁工作原理图

**English Prompt:**
```
Create a professional technical flowchart diagram showing a debounce lock mechanism for server monitoring alerts. The diagram should include:

1. Left side: Timeline showing monitoring data points (CPU/Memory metrics) being collected every 30 seconds
2. Center: Decision diamond "Threshold Exceeded?" 
3. If YES branch: Rectangle "Check Debounce Lock Cache"
4. Second decision diamond "Within Cooldown Period (3 min)?"
5. If YES: Red box "Block Alert (Debounce)" → End
6. If NO branch: Rectangle "Query Historical Trend (30 min window)"
7. Third decision diamond "Trend: Rising/Stable High?"
8. If NO: Yellow box "Suppress Alert (Transient Spike)" → End
9. If YES: Green box "Acquire Lock → Send Alert → Trigger AI Diagnosis" → End

Style: Clean technical diagram with blue/gray color scheme, modern flat design, clear arrows showing flow direction, professional font (Arial or Roboto), white background. Include small icons: lock symbol, clock symbol, trending arrow. Size: 1920x1080px, suitable for academic thesis.
```

## 通用生成建议

### 对于所有技术图表：

1. **分辨率要求**：至少1920x1080px，确保打印清晰
2. **配色方案**：
   - 主色调：专业蓝灰色系（#2C3E50, #3498DB, #ECF0F1）
   - 强调色：橙色（#E67E22）、绿色（#27AE60）、红色（#E74C3C）
   - 背景：纯白色或浅灰色（#F8F9FA）

3. **字体规范**：
   - 英文：Roboto, Arial, Helvetica
   - 中文：思源黑体、微软雅黑
   - 标题：16-20pt 粗体
   - 正文：12-14pt 常规

4. **风格要求**：
   - 扁平化设计（Flat Design）
   - 避免过度装饰
   - 清晰的层次结构
   - 适当留白
   - 统一的图标风格

5. **学术规范**：
   - 符合IEEE/ACM论文图表标准
   - 黑白打印友好（使用图案填充区分而非仅依赖颜色）
   - 清晰的图例说明
   - 适当的标注和箭头

### 使用AI工具建议：

**DALL-E 3 / Midjourney**：
- 添加参数：`--ar 16:9` 或 `--ar 3:2` 控制比例
- 添加：`technical diagram, professional, clean, white background`
- 避免：不要生成真实照片风格，强调 `vector graphic style` 或 `flat design`

**Stable Diffusion**：
- 负向提示词：`text, watermark, signature, blurry, low quality, photorealistic, 3d render`
- 正向提示词加强：`(technical diagram:1.3), (clean layout:1.2), vector graphics, professional infographic`

**备选方案**：
如果AI图像生成效果不理想，建议使用专业工具：
- Draw.io / Diagrams.net（免费，适合所有流程图）
- Lucidchart（云端，模板丰富）
- Microsoft Visio（专业级）
- PlantUML（代码生成UML图）
- Mermaid.live（已提供mermaid代码，可直接渲染）
